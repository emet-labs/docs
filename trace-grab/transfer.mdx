---
title: "Sending your corpus"
description: "How to send your bundle to Emet Labs. trace-grab has no upload command."
---

This guide shows you how to send a bundle to us. trace-grab writes a bundle of plain files to a directory that you name. It has no upload command. It never contacts an Emet endpoint, because the source contains none.

## Before you send

1. Open `report.md` in the output directory. It lists every field path that trace-grab saw and the disposition of each path.
2. Make sure the report matches what you intend to share.
3. To look for one specific value, run `check`. See the [Quickstart](/trace-grab/quickstart).

<Warning>
Pseudonymized data is not anonymous data. Read the [threat model](/trace-grab/threat-model) before you send a bundle.
</Warning>

## Send the bundle

When you are ready, compress the corpus directory and upload the archive.

```sh
tar -czf corpus.tar.gz ./corpus
curl -T corpus.tar.gz "<the URL we gave you>"
```

You can also use any other method that your organization prefers. The corpus is a directory of files on your disk. It does not need the infrastructure of Emet.

## If you find a leak

Deny-by-default means that plaintext reaches the bundle only through a field that a `reveal` rule names. A `reveal` rule with a spelling error or a scope that is too wide fails silently. The run then looks correct.

If you find a leak after you send a corpus, tell us. We do these steps:

1. **Quarantine on detection.** We move the affected batch out of the analysis path immediately. We make no new derived artifacts from it while it is under review.
2. **Notify within one business day.** We tell you what we found and where. We name the field, the disposition rule that let the value through, and the number of records.
3. **Delete on request.** The decision is yours. We ask no questions. We remove the batch and give you written confirmation.
4. **No propagation into derived artifacts.** Deletion covers more than the corpus file. We do not promote any candidate property that the batch fed. We purge aggregates or findings that we kept after deletion.
