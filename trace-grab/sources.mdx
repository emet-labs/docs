This guide shows you how to give trace-grab your input. You can use a file export or the LangSmith API. You can also limit the traces that trace-grab reads.

## Read a file export

We recommend this method. It needs no credentials and works offline. trace-grab reads only the files that you give it.

1. Export your traces. Use a LangSmith export, an OTLP JSON file, or plain span-shaped JSONL.
2. Run `grab` with the path to the export.

```sh
npx @emetlabs/trace-grab grab <path> --out ./corpus
```

If `<path>` is a single file, trace-grab detects the format from the content. To set the format yourself, add `--from langsmith`, `--from otlp`, or `--from generic`.

If `<path>` is a directory, you must add `--from langsmith`. Only the LangSmith export reader can read a directory. It reads every `.json` and `.jsonl` file in the directory.

Auto-detection inspects only a single file. For a directory, any other `--from` value, or no `--from` value, ends with an error. The error tells you what to do. trace-grab does not guess.

## Pull from the LangSmith API

Use this method only if you cannot make a file export.

1. Set `LANGSMITH_API_KEY` in your environment. trace-grab does not accept the key as a flag.
2. Run `grab` with `--from langsmith-api` and the project name.

```sh
LANGSMITH_API_KEY="…" npx @emetlabs/trace-grab grab --from langsmith-api my-project --out ./corpus
```

3. If your key is organization-scoped and needs a workspace, set `LANGSMITH_WORKSPACE_ID`.
4. If you use a different LangSmith base URL, set `LANGSMITH_ENDPOINT`.

If the run stops, run the same command again. trace-grab resumes from its checkpoint. You must use the same `LANGSMITH_API_KEY`.

For the exact requests, the checkpoint, and the credential handling, see [LangSmith API source](/trace-grab/reference/cli#langsmith-api-source).

## Limit the traces that trace-grab reads

Every `grab` command accepts these flags:

- `--since <iso>` and `--until <iso>` keep only traces that overlap this time window.
- `--max-traces <n>` limits the number of traces that trace-grab writes.

trace-grab applies these limits to whole traces, after it reads the records. A limited corpus never contains a child span without its root.
