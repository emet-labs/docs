trace-grab is not a product. It is also not a general-purpose tool. You use it to donate traces to Emet Labs research without giving us anything sensitive.

You point trace-grab at a trace export that you already have. It reads the export and replaces every string value with a stable token. It writes a plain JSONL bundle to a folder on your own disk. There is no server, no account, and no upload step.

The source contains no code path that sends your data anywhere else. You can check this claim yourself. You do not need to trust us. See the [threat model](/trace-grab/threat-model).

## What you do with the output

Read the output before you decide anything. trace-grab writes `report.md` next to the bundle. This file lists every field that trace-grab saw. It also gives the action for each field: tokenized, revealed, dropped, or passed unchanged.

If the output is correct, send it to us. If it is not correct, delete the folder. trace-grab did not send any of it.

## What changes in your data

By default, trace-grab turns every string into a token. One exception exists. A short, documented list of fields stays unchanged, for example tool names, span names, and status codes. These fields do not carry content on their own.

Numbers, booleans, and timestamps pass unchanged. They are seldom the reason that a trace is sensitive.

```jsonc
// before
{ "name": "modify_account", "inputs": { "account": "acct_1208", "actor": "alice@corp.com" } }

// after
{ "name": "modify_account", "inputs": { "account": "TOK_4f1ab9c072", "actor": "TOK_88b0e13a5d" } }
```

The same value always gives the same token. Two records that contain `acct_1208` show the same token. The shape of your traces stays, but the content does not.

A person who holds only your bundle cannot work backward to `acct_1208`. Only you can do this. You need the salt and the keymap, and both stay on your machine.

## Why trace-grab exists

We build and test Sentinel with real trace data. Most partners cannot give us raw logs. The logs hold customer data, internal tool names, and sometimes healthcare or financial content.

We ask these partners to run trace-grab themselves. They keep the files that let them read their own output. They send the bundle only when they accept its content.
